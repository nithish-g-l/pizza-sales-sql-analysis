# Pizza Sales Analysis using SQL

A SQL-based data analysis project that explores pizza sales data using MySQL. This project demonstrates SQL concepts ranging from basic queries to advanced analytical functions to derive meaningful business insights.

## Project Overview

The objective of this project is to analyze a pizza store's sales data and answer various business questions using SQL.

The project covers:
- Data aggregation
- Joins
- Group By
- Subqueries
- Window Functions
- Ranking Functions
- Revenue Analysis
- Sales Performance Metrics

---

## Database Schema

The project uses the following tables:

- **orders**
  - Stores customer order information
  - Order ID
  - Order Date
  - Order Time

- **order_details**
  - Stores pizzas ordered in each order
  - Order Detail ID
  - Order ID
  - Pizza ID
  - Quantity

- **pizzas**
  - Stores pizza size and price information
  - pizza_id
  - pizza_type_id
  - size
  - price

- **pizza_types**
  - Stores pizza names and categories
  - pizza_type_id
  - name
  - category
  - igredients

## Business Questions Solved

### Basic Analysis

- Retrieve the total number of orders placed.
- Calculate total revenue generated.
- Find the highest-priced pizza.
- Identify the most commonly ordered pizza size.
- List the Top 5 most ordered pizzas.

---

### Intermediate Analysis

- Total quantity ordered by pizza category.
- Distribution of orders by hour.
- Category-wise pizza distribution.
- Average pizzas ordered per day.
- Top 3 pizzas based on revenue.

---

### Advanced Analysis

- Percentage contribution of each pizza category to total revenue.
- Cumulative revenue over time using Window Functions.
- Top 3 revenue-generating pizzas within each category using RANK().
